## Anthropic / Claude updates
- **Known upstream issue matches this project's own 09-13 failure.** [anthropics/claude-code#86074](https://github.com/anthropics/claude-code/issues/86074) — "`claude -p` has no API request timeout — black-holed TCP connection hangs headless run indefinitely" — describes exactly the failure mode behind the `claude CLI timed out after 600s on all 3 attempts` incident. Acknowledged, currently-open upstream gap, not fixable from this repo. `core/scorer.py`'s own `subprocess.run(..., timeout=600)` + retry-on-`TimeoutExpired` (lines ~1121–1145) is already the correct mitigation — confirming existing design is right, not proposing a change.
- Related: [#59573](https://github.com/anthropics/claude-code/issues/59573) — `claude --print` can hang (not error) on large prompts (~30KB+/~10K tokens) with a Sonnet model, stalling after the first chunk. Relevant if scorer batch sizes grow.
- **Official guidance** ([platform.claude.com/docs/api/errors#long-requests](https://platform.claude.com/docs/en/api/errors#long-requests)): for Messages API calls risking >10 min, use streaming or the Message Batches API instead of one blocking call. This targets the metered Messages API, not the CLI this project calls — adopting it means moving off `backend="cli"`, blocked by this project's own `api_spend_authorized` policy. A real option, not a free one.
- Anthropic SDKs default to exponential backoff **with jitter** (500ms base) on retries; `core/scorer.py`'s CLI retry loop uses flat 5s sleep, no jitter. Cheap polish, not worth a standalone backlog item.
- **Structured Outputs is GA** (`output_format` param, beta header `structured-outputs-2025-11-13`), grammar-constrains JSON at the token level, listed for Sonnet 4.5/Opus 4.1 (Haiku 4.5 coverage unconfirmed). API-only — not exposed via the CLI's `--output-format json` flag, so it wouldn't close the "unvalidated CLI JSON" gap `score_via_cli`'s own docstring flags unless the project moves to `backend="api"`.
- Sonnet 5 pricing ($2/$10 per M tokens) is now standard — the planned Sept 1 increase to $3/$15 didn't happen. No action needed.
